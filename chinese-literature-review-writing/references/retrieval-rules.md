# 文献检索与筛选规则

用户要求检索、补充、替换或筛选综述文献时读取本文件。检索结果必须兼顾主题相关性、来源质量、时间范围和可核验性，不能只追求期刊或院校名气。

## 一、确定检索范围

1. 将论文主题拆成核心概念、同义词、上位词、下位词、研究对象、应用情境和方法词。
2. 同时建立中文与英文关键词组，记录不同学科常用译法。
3. 明确纳入和排除条件，包括年份、语言、地区、对象、文献类型和研究问题。
4. 先宽检索，再根据标题、摘要、关键词和全文逐级筛选。
5. 记录数据库、检索日期、检索式和筛选理由，保证结果可以复查。

## 二、执行近 3—5 年规则

- 以实际检索日期为基准，默认将近 3—5 年文献作为综述主体，并在结果中写明起止年份。
- 优先使用最新研究解释当前现象、政策环境、技术变化和近期争议。
- 保留必要的早期文献时，注明其用途，例如概念首提、理论奠基、经典量表、方法来源、政策源流或重要历史转折。
- 近年高质量文献不足时，可以适度向前扩展，但须说明扩展范围和原因。
- 不为满足年份要求排除与研究问题直接相关的经典来源，也不以“较新”为由纳入关联度低的文献。

## 三、筛选国内期刊

按学科选择适当的核心认定体系：

- 人文社会科学优先核验 CSSCI 来源期刊、CSSCI 扩展版和《中文核心期刊要目总览》，并区分不同目录；
- 自然科学和工程技术根据专业核验 CSCD、科技核心及学校认可目录；
- 医学、管理、教育等交叉领域同时遵循学校、学院或目标期刊的明确要求；
- 学校提供目录时，以学校当前有效目录为优先依据。

记录目录名称、版本或年份。不要凭期刊名称、主办单位或过往印象判断“核心”，也不要把 CSSCI、北大核心、CSCD 和科技核心写成同一概念。

## 四、筛选国外期刊

- 优先选择与主题直接相关、经过同行评议并被学科权威数据库稳定收录的期刊论文。
- 根据学科核验 Web of Science Core Collection、Scopus、JCR、CiteScore 或公认学科期刊目录，但不要把数据库收录等同于论文质量。
- 引用分区时注明评价体系和年份，例如 JCR 分区与中科院分区不得混写。
- 优先保留高相关的研究论文、系统综述或权威综述，用其补足理论、方法和国际证据。
- 排除来源不明、疑似掠夺性、仅有宣传页面、无法核验元数据或与主题弱相关的内容。

“国外核心期刊”不是统一目录。若用户或学校没有指定标准，必须说明本次采用的数据库、分区或学科目录。

## 五、筛选硕士论文

硕士论文同时满足以下条件时再优先纳入：

1. 研究问题、对象、变量或应用情境与主题直接相关；
2. 学位授予单位在对应学科或专业上具有较强实力；
3. 论文元数据、学位授予单位、专业名称和年份可以核验；
4. 论文能提供核心期刊尚未覆盖的本土案例、细分对象、方法细节或新近材料。

判断院校学科实力时：

- 优先采用官方学科评估、政府或教育主管部门公开资料，以及用户认可的权威学科排名；
- 对国外院校优先核验对应学科排名、院系声誉或权威专业目录，不只看学校综合排名；
- 明确记录排名或评估名称、版本、年份和学科；
- 不凭学校名气自行认定“排名靠前”；
- 无法核验时标记 `[院校学科实力待核验]`，不要补造名次。

硕士论文属于补充证据，不能用来替代近年核心期刊构成的主体证据。若硕士论文与高质量期刊结论冲突，须比较研究设计和证据强度。

## 六、确定来源优先级

在相关性相当时，依次优先：

1. 近 3—5 年国内外核心或学科高质量期刊论文；
2. 能解释理论源流、概念或经典方法的必要早期文献；
3. 对应学科实力靠前院校、且与主题高度相关的硕士论文；
4. 能补充特定案例或材料的其他可核验学术来源。

任何层级都不得绕过真实性核验。相关性不足的高层级来源，应排除或仅列入背景材料。

## 七、记录筛选结果

为每篇候选文献记录：

| 字段 | 要求 |
|---|---|
| 题名、作者、年份 | 与原始来源一致 |
| 文献类型 | 期刊论文、硕士论文、综述等 |
| 主题相关性 | 高、中、低，并用一句话说明依据 |
| 期刊质量依据 | 核心目录、数据库收录、分区及版本年份 |
| 学位论文质量依据 | 院校、学科、排名或评估名称及年份 |
| 主要内容 | 研究问题、对象、方法和可核验结论 |
| 来源位置 | DOI、数据库记录、机构库页面或全文位置 |
| 核验状态 | 已读全文、仅核验摘要、仅核验元数据、待核验 |
| 纳入决定 | 核心文献、补充文献、背景文献或排除 |

## 八、报告检索质量

交付结果时简要说明：

- 实际检索的起止年份；
- 使用的中英文数据库或来源；
- 国内核心目录和国外期刊认定标准；
- 硕士论文采用的院校学科实力判断标准；
- 超出 3—5 年范围但被保留的经典文献及理由；
- 尚未获得全文、核心属性或排名依据的待核验项。

核心目录、分区和学科排名会变化。每次实际检索时都要查询当前或任务指定年份的可靠来源，不沿用记忆中的旧名单。
