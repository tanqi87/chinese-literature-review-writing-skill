# 中文论文综述写作

## 坚持证据先行

- 只把用户提供的原文、可核验的文献记录或已打开的可靠来源当作事实依据。
- 区分“文献明确陈述”“根据多篇文献作出的综合判断”和“待核验的写作建议”。
- 不编造作者、题名、期刊、年份、页码、DOI、网址、数据、结论或学校要求。
- 保留原有引文编号和作者—年份标注，不擅自替换引用关系。
- 无法核验的内容用 `[待核验]`、`[缺少来源]` 或明确占位符标出，不把占位符伪装成正式引文。
- 不承诺查重率或 AIGC 检测结果。若任务核心只是对已有标红段落降 AIGC，改用 `chinese-thesis-aigc-revision`；若还涉及文献分组、论证和研究述评，则继续使用本技能。

## 把握“沿袭与创新”

遵循“先读、综合、再写”的顺序。没有完成必要阅读和证据盘点时，不直接拼接成稿；输入不足时，先输出检索方案、证据矩阵或待核验清单。

先判断用户需要的是独立的综述文章，还是论文导论或正文中的综述部分。两者篇幅和结构不同，但都要完成以下任务：

- 交代该领域已经形成的主要问题、理论、方法、发现和争议；
- 说明各类研究之间如何承接、对话或分歧，而不是只列作者观点；
- 根据可核验证据指出目前知道什么、仍不知道什么；
- 解释未解决问题为何重要，以及它如何引出本文的研究问题；
- 让本文进入已有学术讨论，并清楚说明可能增加的对象、材料、方法、解释或适用条件。

“沿袭”不是复述前人，而是交代研究依赖的知识基础；“创新”也不是宣称“首次”或“填补空白”，而是在充分阅读后，通过新的分类、比较、解释或研究设计推进现有讨论。

写作时以“综合”为主、“总结”为辅。总结负责忠实概括单篇文献，综合则要把多篇文献放入同一分析框架，比较其问题、理论、方法、样本、结论和边界，并形成有证据支持的判断。创新性评述必须来自这种比较，不能来自补造观点。

## 选择工作模式

根据材料完整度选择最小可行任务，不因缺少非关键偏好反复追问。

| 用户材料 | 执行动作 |
|---|---|
| 只有选题或研究方向 | 界定概念、拆分检索主题、给出检索式和综述框架；不生成带虚构引文的成稿 |
| 有文献表、摘要、笔记或原文 | 建立证据矩阵，按主题、争议、方法或时间演变归组 |
| 有综述初稿 | 诊断堆砌、重复、跳跃、引用错位和评述空泛，再保留事实与引文进行修改 |
| 有完整材料并要求成稿 | 先完成证据归组和提纲，再写正文、研究述评及核验清单 |
| 有学校模板或导师意见 | 把明确要求视为最高优先级；无法确认的口头规则提醒用户向学校核验 |

## 收集必要信息

优先确定：

- 研究主题、核心概念和边界；
- 学科与论文层次；
- 综述用途，如开题、论文正文、课程论文或投稿；
- 字数、年代范围、国内外范围和引用格式；
- 用户已经提供的文献、笔记、初稿、导师意见与模板。

若用户未给出可选项，默认采用中文自然学术表达、主题式组织，并沿用原材料的引用格式。只在缺失信息会实质改变结果时询问；否则先做可逆的内容盘点，并说明关键假设。

## 检索与筛选文献

用户要求检索、补充或筛选文献时，读取 [references/retrieval-rules.md](references/retrieval-rules.md)，并采用以下默认标准：

- 以检索时点向前推算的近 3—5 年研究为主体，明确写出实际起止年份；
- 国内外文献均优先选择与主题直接相关的核心期刊或学科公认高质量期刊；
- 国内“核心”须按学科核验 CSSCI、北大核心、CSCD、科技核心或学校指定目录，不能混用不同体系；
- 国外期刊须核验同行评议、数据库收录和分区或学科地位，不能把普通外文期刊直接称为“核心”；
- 与主题相关的硕士论文只作补充证据，并优先选择对应学科或专业实力靠前院校的成果；
- 判断院校实力时优先使用学科排名或学科评估，不用学校综合排名代替专业实力；
- 核心目录、数据库收录、期刊分区和学科排名均须注明核验依据、版本或年份；
- 奠基性理论、经典量表、概念源流和必要政策材料可突破 3—5 年限制，但须说明保留理由。

相关性具有否决权。即使期刊层级较高或院校排名靠前，只要研究问题、对象或情境与主题关联不足，就不纳入核心文献。

## 建立证据矩阵

在写长篇正文前，提取并记录以下字段：

| 字段 | 内容 |
|---|---|
| 文献标识 | 原引用编号或作者—年份 |
| 文献类型与年份 | 期刊论文、硕士论文、综述等及正式发表年份 |
| 来源质量依据 | 核心目录、数据库收录、分区，或学位授予单位的学科排名依据 |
| 研究问题 | 文献实际回答的问题 |
| 对象与情境 | 地区、行业、群体、时期等 |
| 理论或概念 | 文献明确使用的理论、模型和定义 |
| 方法与材料 | 样本、数据、实验、访谈、文本或案例 |
| 主要发现 | 可由原文支持的结论 |
| 局限或边界 | 作者自述或可由设计直接判断的限制 |
| 证据位置 | 页码、章节、表格或用户笔记位置 |
| 核验状态 | 已读原文、仅核验元数据、用户笔记、待核验 |

精确数字、直接引语、样本规模、页码和因果结论必须有可定位依据。只看到摘要时，不推断正文中的方法细节或研究局限。

## 确定组织逻辑

优先按研究问题或主题组织，避免逐篇写成“作者 A 认为……作者 B 认为……”的资料清单。根据内容选择：

- **主题式**：适合大多数社会科学综述，用并列或递进的研究议题组织；
- **争议式**：围绕不同结论、解释或理论立场展开比较；
- **方法式**：比较定量、定性、实验、案例或文本研究的证据差异；
- **时间式**：只有研究演变确实重要时才按阶段梳理；
- **理论式**：比较概念定义、理论假设和解释范围；
- **混合式**：先按主题分组，再在组内说明时间、方法或地区差异。

只有用户或学校明确要求时，才机械分成“国外研究现状”和“国内研究现状”。可以分区写作，但必须在研究述评中进行跨区域比较。

## 搭建论证

按需要安排以下层次：

1. 界定综述对象、核心概念和纳入范围。
2. 提炼主要研究群组，而不是复述检索过程。
3. 比较各群组的对象、理论、方法、结论与适用条件。
4. 说明共识、分歧、演变和证据强弱。
5. 提出有依据的局限或未解决问题。
6. 解释这些问题如何引出用户自己的研究问题、变量、对象或方法。
7. 明确本文与已有讨论的承接关系，以及准备增加的具体证据或解释。

不要把“没有检索到”直接写成“尚无学者研究”。不要为了突出创新而夸大既有研究的不足。

## 写作段落

围绕一个中心判断组织每段，可灵活使用以下顺序：

1. 用主题句交代本段讨论的研究问题或判断；
2. 合并呈现能够共同支持该判断的文献；
3. 比较差异、适用条件或证据强弱；
4. 给出有限度的解释或评述；
5. 用过渡句连接下一主题或本文研究。

让引文紧跟其支持的陈述。多篇文献观点相近时进行综合转述，不重复相同句式；观点不同时准确标明分歧，不能强行归为共识。

## 遵循默认文风

- 使用明确主语和实义动词，控制长句，保证观点、依据和解释相连。
- 保持自然、稳妥的学术语气，不堆“首先、其次、再次”等机械连接词。
- 少用空泛的“赋能、路径、机制、体系、协同”；确需使用时说明具体对象与作用关系。
- 避免“随着……不断发展”“国内外学者进行了大量研究”等无信息开头。
- 让段落长短和句式有自然变化，不为“学术感”堆名词或刻意整齐。
- 根据证据强度选择“显示、表明、提示、可能、在……条件下”等措辞，避免把相关关系写成因果关系。

写作或深度修改正文时，读取 [references/writing-rules.md](references/writing-rules.md)，执行其中的结构模板、表达偏好和检查清单。

## 输出结果

根据用户任务选取必要部分，不强制输出完整流程：

- **材料盘点**：已有材料、可用证据、缺失信息和核验状态；
- **文献矩阵**：适合资料较多、需要继续补文献或团队协作时；
- **综述提纲**：每一节写明核心问题、拟用文献群和该节作用；
- **正文或修改稿**：直接给可用文本，保留引用格式；
- **修改说明**：只列结构、逻辑和证据层面的关键改动；
- **核验清单**：列出待补页码、待确认出处、缺失元数据和不宜直接使用的判断。

若用户要求参考文献表，只输出已由用户提供或已经核验的条目。元数据不完整时保留待补字段，不补造信息。

## 完成前检查

- 确认每个具体事实、数字、引语和引用均有对应来源。
- 确认没有把一篇文献的结论误配给另一条引文。
- 确认综述存在归组、比较与评述，而非逐篇摘要。
- 确认正文体现“先读、综合、再写”，并说明本文与已有学术讨论的承接关系。
- 确认所谓创新落到对象、材料、理论、方法、解释或适用条件，而非空泛宣称。
- 确认“研究不足”能够由材料支持，并与用户研究问题相关。
- 确认概念、变量、对象称谓和时态前后一致。
- 确认没有擅自改变用户数据、原结论、引用编号和参考文献格式。
- 确认近 3—5 年文献构成主体，超出时间范围的文献均有保留理由。
- 确认期刊核心属性、数据库收录、分区和院校学科排名均注明版本或年份。
- 确认没有用学校综合排名替代对应专业或学科实力判断。
- 确认所有不确定内容均已显式标注，且没有虚构文献或规则。
